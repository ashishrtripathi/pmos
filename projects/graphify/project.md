# Graphify

## Project Overview

Graphify maps an entire codebase (code, docs, PDFs, images, videos) into a queryable **knowledge graph** — you ask questions or trace relationships instead of grepping files. Type `/graphify` in an AI coding assistant; code is parsed with tree-sitter AST (deterministic, fully local, no LLM), every edge is tagged `EXTRACTED` (explicit in source) or `INFERRED` (resolved by graphify), and output is a real traversable graph (not a vector index). From Graphify Labs (YC S26).
