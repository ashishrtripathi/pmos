# Customer Journey — Dev (Full-Stack Developer)

**Persona**: Full-Stack Developer / Technical Lead, 32, Expert
**Quote**: "I want to add features to PMOS without fighting the architecture. The file-based design should make this easy."

---

### Journey Steps (Left -> Right)

| Step | Activity | Tasks | Pain Points | Screen |
|------|----------|-------|-------------|--------|
| **1. Setup** | Connect project & run dev environment | Clone repo, attach local folder or GitHub repo, npm install, npm run dev, understand structure | Where is UI code vs metadata? How to add pages? What files to touch? | ![Setup -> Source configuration](screens/setup.png) |
| **2. Pipeline** | Run the 9-step pipeline | Execute steps, monitor progress, continue from failure, verify output files | Where to find errors? How to reset a step? | ![Pipeline -> 9-step execution flow](screens/pipeline.png) |
| **3. Intelligence** | Ingest codebase analysis | Read architecture, tech-stack, features, quality findings, trigger re-scan | Verify AI understood the code, find what's new vs tracked | ![Intelligence -> Analysis tabs](screens/intelligence.png) |
| **4. OKRs** | Define and track quarterly objectives | Create OKRs, link key results, track progress, align stories | Where to see goal progress? How to link stories to OKRs? | ![Dashboard -> Project health](screens/dashboard.png) |
| **5. Journey** | Map customer journeys | View personas, edit step tables, update pain points, preview UI | Keep journey in sync with UI steps, per-persona journeys | ![Journey -> Persona tabs](screens/journey.png) |
| **6. Story Map** | Build the story map | Arrange stories under backbone steps, assign personas, write Gherkin AC, estimate costs | Stories trace to persona/step, see token costs and dollars, ROI | ![Story Map -> Journey columns](screens/story-map.png) |
| **7. Kanban** | Manage delivery on the board | Drag stories between columns, assign agents, update agentWork, close stories | Server vs client state, drag-and-drop consistency, heartbeats | ![Kanban -> Columns with drag-and-drop](screens/kanban.png) |
| **8. Standup** | Run daily standup | Review in-progress work, check blockers, plan next, share with team | See progress without status meetings, surface stale work | ![Dashboard -> Standup summary](screens/dashboard.png) |
| **9. Bugs** | Track and fix defects | File bugs, triage, link to stories, verify fixes, close | Reproduce steps, trace bug to story, regression risk | ![Stories -> Bug tracking](screens/stories.png) |
| **10. Agents** | Dispatch and review agents | Review agent profiles, assign stories, monitor agent work, approve output | Know which agent does what, check agent load, verify commits | ![Agents -> Dispatch panel](screens/agents.png) |
